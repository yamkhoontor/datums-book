# Datums, Coordinate Systems and Map Projections

**A Practical Guide for Surveyors and Engineers, with SVY21 Worked Examples**
by Yam Khoon Tor

This repository holds the companion browser apps of the book.

## Use the apps online (no installation)

Open **https://yamkhoontor.github.io/datums-book/** in a web browser. There is one app for each chapter. At the top of each app is a button for each worked example in the chapter: press one, and the app loads the example's values and highlights the results that the example computes, with the book's values to compare. Change any input and the results update at once.

## Use the apps offline

Press the green **Code** button on this page, choose **Download ZIP**, unzip it and open `apps/index.html` in a web browser. The apps then run entirely on your own device, with no internet connection.

## Sources

Coastlines in the apps: OpenStreetMap data (© OpenStreetMap contributors, ODbL), via geo-maps. Projection and transformation parameters: SLA, JUPEM, BIG, the Survey Department of Brunei and the EPSG registry, as cited in the book.

The apps are teaching aids, not certified survey software.
